# Introduction to Machine Learning

## Overview
This repository contains my assignments for the Introduction to Machine Learning track of a Data Science and Machine Learning Bootcamp.  
It focuses on building and evaluating machine learning models, including preprocessing, regression, classification, and model interpretation.



## Topics Covered
- Introduction to Machine Learning & Preprocessing
- Regression Models (Linear Regression, Ensemble Trees)
- Classification Models (Logistic Regression, KNN, Decision Trees, Random Forest)
- Model Evaluation Metrics (Accuracy, Recall, F1-score, RMSE, R²)



## Assignments
- Assignment 01: Column Transformer 
- Assignment 02: Abalone
- Assignment 03: Model Pipeline  
- Assignment 04: Ensemble Trees  
- Assignment 05: Classification Metrics  
- Assignment 06: Stroke Detection  



## Goal
Develop practical machine learning skills by building end-to-end pipelines, training different models, and understanding how to evaluate and optimize them for real-world datasets.
